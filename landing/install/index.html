SokeriPilot

Install guide

From download to the cockpit.

SokeriPilot is installed from this site, not from Play, so Android shows two extra prompts and Android Auto hides one setting. Five steps, about three minutes. You need Android 8.0 or newer, the Android Auto app and a compatible car or the Desktop Head Unit.

  1. 1. Download the APK on the phone

    Open this page on the phone (the QR code on the home page is the shortcut) and tap Download APK. The file is SokeriPilot-1.2.1.apk, 0.9 MB, signed with the project's release key. Chrome keeps it in Downloads.

  2. 2. Allow the install

    Tap the downloaded file. Android asks whether Chrome may install unknown apps: open Settings → Apps → Special app access → Install unknown apps → Chrome and allow it, then go back. Play Protect may also warn about an app it has not seen before — choose Install anyway. If it only offers Scan app, run the scan once and install again.

    You can revoke that Chrome permission straight after installing; SokeriPilot does not need it.

  3. 3. Grant notification access

    Open SokeriPilot and tap Allow notification access. This is the single system toggle that lets the app read the value your CGM app already posts — there is no setting to change inside Dexcom, Libre, xDrip+, Juggluco or any other sensor app.

    If the value does not arrive, open the Source check card on the phone screen: it shows the last reading, the app it came from, and the last ten CGM-looking notifications marked accepted or rejected with the reason.

  4. 4. Make SokeriPilot appear in Android Auto

    Android Auto lists Play-installed apps by default. Open the Android Auto app on the phone, scroll to the version number at the bottom of Settings and tap it ten times to enable developer mode. Then open the three-dot menu → Developer settings and turn on Unknown sources. Reconnect the phone: SokeriPilot now appears in the car launcher under the app grid.

    The setting is per phone and survives reboots. If the car still does not show the app, open SokeriPilot once on the phone while it is projected, then check the car launcher again.

  5. 5. Keep the notification alive

    Driving mode uses a foreground service, and Android may freeze background apps to save power. Set Settings → Apps → SokeriPilot → Battery → Unrestricted. On longer drives keep the phone plugged in. The cockpit always shows the reading age, so a stale value never looks current.

When something does not work

SymptomCheck
No SokeriPilot icon in the car Developer mode and Unknown sources in the Android Auto app; the phone must be projected, not just charging.
Car notification stops updating Battery setting Unrestricted; driving mode on; the phone is not in deep sleep.
“No glucose data” while the sensor app shows a value Notification access granted to SokeriPilot; the CGM app posts its value as a notification; Source check explains each rejected notification.
Play Protect blocks the install Install anyway, or scan once and install again. The APK's SHA-256 is on this site to compare.
“App not installed” over an older copy The previous install was signed with another key. Uninstall once, then install this file; settings stored by the old copy are lost.
Nightscout rejects the key Only HTTPS sites are accepted; the key is stored as the SHA-1 digest Nightscout expects. API_SECRET must be set on the server.

Verify the file you installed

Every release is listed with its size, SHA-256 and signing certificate on the release archive. On a computer, compare the download:

sha256sum SokeriPilot-1.2.1.apk

The current build's digest starts with 457a885f. The signing certificate must be the same on every version, otherwise Android cannot install one over the other.
